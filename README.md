A 60 FPS browser flight simulator and aerial sortie game set over a sunlit volcanic archipelago, canyons, and a PAPI-lit coastal airstrip.

## Features

- **3D Perspective Chase & Cockpit HUD Engine**: Shaded volcanic islands, lava caldera crater, turquoise coastal reefs, Twin Spire Canyon, volumetric clouds, and a twin-tail Valkyrie aircraft with animated flaps, retractable landing gear, nav lights, wingtip contrails, and afterburner plumes.
- **Glass-Cockpit Avionics**: Pitch ladder, artificial horizon, velocity flight-path marker, IAS (`KTS`), `ALT FT` + `AGL`, Vertical Speed (`FPM`), Heading Compass Tape (`HDG`), Fuel/Hull/Throttle gauges, and ILS Localizer / `3.2°` Glide-Slope indicators.
- **3 Sortie Missions**:
  1. **Archipelago Ring Slalom** — 8 canyon, ocean, and caldera target gates.
  2. **Coastal Touch-and-Go** — PAPI-guided (`2 white / 2 red`) approach onto Runway 36.
  3. **Storm Recon Patrol** — Low-altitude ridge gates with shifting wind shear and turbulence.
- **Procedural WebAudio**: Dynamic turbine hum, airflow rush, afterburner hiss, stall warning alerts, gate chimes, and touchdown audio.

## Controls

| Key | Action |
| :--- | :--- |
| `W` / `S` or `↑` / `↓` | Pitch (`I` to invert yoke) |
| `A` / `D` or `←` / `→` | Roll / Bank-to-Turn |
| `Q` / `E` | Rudder Yaw |
| `Shift` / `Ctrl` or `+` / `-` | Throttle Up / Down |
| `Space` | Boost / Afterburner |
| `G` / `F` / `B` | Landing Gear / Flaps / Airbrake |
| `C` / `M` / `V` | Chase-Cockpit Camera / Mouse Yoke / Audio |
